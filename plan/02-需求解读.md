## 4. 边界与非目标（防 scope 失控，承接 01 §六）

**不做**（做了算 scope 失控）：
- 真实患者数据：全部合成，患者姓名/住院号虚构；
- 临床诊断或治疗建议：本系统只做**书写质量与记录一致性质控，不是临床决策支持工具**（报告与 README 必须带免责声明）；
- 影像/病理切片判读；HIS/EMR 系统对接；移动端；
- OCR/打印体扫描件解析（FR-14 加分项，仅在主线全部达标后视进度考虑）；
- 姊妹项目代码复用：与 construction-drawing-plan-checker、power-operation-ticket-checker 同方法论、代码不共享、业务互不提及。

**结论纪律**（红线）：
- 数值与条文结论只来自确定性规则 + 已核对依据；LLM 仅兜底抽取、复核与行文；
- 知识库每条挂"文号+条款+渠道+status"；无出处/待核对的条目不得以确定语气写入结论；
- 合成数据标注"模拟数据不构成诊疗依据"。

**非功能需求**：
- 可复现：数据生成固定 seed；基准零 API 依赖；
- 断网可演示：Web 页面 0 外链；基准/测试全离线（LLM 相关测试用 mock）；
- 兼容：Python ≥3.8（本机 3.8.8 实测）；核心通路零第三方依赖；
- 失败路径兜底：缺文件/坏格式/依赖缺失/LLM 不可达 → 降级不崩溃，测试覆盖。
