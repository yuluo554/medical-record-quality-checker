# 05 数据计划与里程碑

> 定稿 2026-10-03。台账见 [data/README.md](../data/README.md)。

## 1. 数据四类目录与来源策略

| 目录 | 内容 | 来源 | 许可/合规 |
|---|---|---|---|
| `data/templates/` | 病种病历模板（部件骨架+字段槽位） | 程序化自制（公开临床常识口径） | 自制，"模拟数据不构成诊疗依据" |
| `data/samples/` | 合成病历部件集合 + truth.json（参数卡真值） | 生成器产出，固定 seed | 自制，全部虚构身份 |
| `data/paired/` | 植入缺陷配对评测集 + defects.json | 生成器注入产出，固定 seed | 自制 |
| `data/knowledge/` | raw 规范原文 / blocks 条文块 / rules 规则表 | 国家卫健委公开文件（逐份挂渠道+URL+日期） | 官方公开文本，条目挂出处，status 标注 |

**核心资产是程序化自制带真值数据**：没有真实标注病历可用，且真实病历涉隐私——生成器（模板+随机+注入）解决"无标注数据"死结，评测可零成本重复。

## 2. 病种模板设计（M1）

3 个病种覆盖两类诊疗形态：

| 病种 | 形态 | 覆盖的检查通道 |
|---|---|---|
| 社区获得性肺炎 | 内科用药型 | 诊断-用药匹配、抗菌药物分级、检验异常处置、危急值闭环 |
| 急性阑尾炎（阑尾切除术） | 外科手术型 | 手术-术前讨论/知情同意一致、术后病程时效、签名资质 |
| 胆囊结石（腹腔镜胆囊切除术） | 外科手术型 | 术式一致性、医嘱停止-出院时间、术中用血（变体） |

每模板含：六部件文本骨架、参数卡字段槽位（含合法值域）、可注入缺陷位置标记。患者身份由姓名池+住院号序列随机合成，与病种/性别/年龄约束合法性校验。

## 3. 生成器（`src/mrqc/datagen/`，M1）

```
py -X utf8 -m mrqc.datagen --out data/samples --count 60 --seed 20261003
py -X utf8 -m mrqc.datagen --out data/paired --paired --per-defect 3 --seed 20261004
```

- 输入：模板 + seed；输出：每份病历一个目录（6 部件 txt）+ `truth.json`（参数卡形状真值）+ 配对集额外 `defects.json`（注入清单：defect_id=规则 ID、注入参数、also_expect）；
- 干净集（无注入）与注入集分开产出；同一 seed 位级可复现（重跑 `git status` 零变化，纳入回归）；
- 注入器与规则 ID 对照表见 [04-模块详设.md §7](04-模块详设.md)；同一参数的注入互斥坑（如同时注入"术式不一致"与"术者不一致"需错开字段）在生成器模块注释记录；
- 数据规模目标：samples ≥60 份（3 病种 × ≥20）；paired 每缺陷类型 ≥3 份 + 干净对照 ≥10 份。

## 4. 知识库数据计划（M1 raw / M3 块+规则）

5 份核心文件 ✅ **M1 已全部入库**（2026-10-03，逐份登记见 [data/README.md](../data/README.md) 登记表三）：

- 卫医政发〔2010〕11号、国卫办医发〔2016〕24号、国卫医发〔2018〕8号、国卫医发〔2013〕31号：官网页面逐字提取入库（4 份 txt）；
- 国卫办医函〔2021〕28号：印发通知逐字 + 官方附件 PDF 原件（11 页）+ pypdf 文本层提取，三件套入库。

获取通路实录：卫健委官网 WAF 对 curl/WebFetch 返回 412 挑战页，真实浏览器渲染通过挑战后逐字提取正文（`.con` 容器 innerText）；附件 PDF 走 `files/` 直链 curl 下载。搜索引擎摘要与模型转述内容均不采信（其中一处转述曾把 2013 病历管理规定文号误作"卫医政发〔2013〕28号"，官网实写国卫医发〔2013〕31号，以官网为准）。

入库纪律：条文数值（时限/保存期限/指标定义）以官方原文为准；查证失败 → 登记"待核对"继续推进，不编造；搜索引擎摘要不采信，只认可直连的官方页面原文。
