## 里程碑（初稿，02/05 定稿时细化）

- M1 数据先行：病历部件模板（入院/病程/手术/出院/医嘱/检验）+ 合成生成器（带真值/植入缺陷）+ 数据台账
- M2 解析层：多部件文本解析器 → 病历参数卡，回归测试
- M3 知识与规则：规范三层知识库 + 形式/内涵双通道规则引擎（含类目门控），依据关联
- M4 LLM 兜底 + 内置基准：解析 F1 ≥0.95、误报 0
- M5 编排与交付：CLI + docx 质控报告 + Web 面板（0 外链）
- M6 脱敏发布 GitHub + 收尾固化（tag/release/topics）
