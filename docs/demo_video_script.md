# 演示视频脚本（M5 交付物）

> 目标时长约 4 分钟，1080p，全程终端 + 浏览器录屏，无外部素材依赖（与项目 0 外链纪律一致）。
> 录制环境：Python 3.8，`py -X utf8`；命令均在仓库根目录执行。
> 录制前自查：`py -X utf8 -m mrqc demo` 尾部路线图应显示 M0–M5 全 ✅。

## 分镜脚本

### 镜头 1｜开场（约 30 秒）

画面：项目 README 首屏（免责声明置顶）。

口播：
"病历质控分两层：形式质控已有成熟工具，而**内涵质控**——诊断与用药一致性、手术与病程记录矛盾、危急值闭环——靠人工抽查难以覆盖，还直接关联医保拒赔与纠纷风险。开源界一直没有可复现的参考实现。这个项目就是那块拼图：**出院病历内涵质控智能审核系统**，规则优先、LLM 只兜底，每条结论强制挂规范依据。"

字幕要点：形式质控 vs 内涵质控；「不是临床决策支持工具」免责声明必须停留可读。

### 镜头 2｜数据先行（约 30 秒）

画面：终端执行，右侧文件树展示 data/ 目录。

```bash
py -X utf8 -m mrqc.datagen --verify data/samples data/paired
ls data/paired | head
cat data/paired/defect_C-LAB-02_01/defects.json
```

口播：
"数据先行：三个常见病种模板，固定 seed 生成 60 份训练样本和 54 份配对评测集——14 类缺陷 ID 程序化植入，每份病历自带真值，重跑位级一致。评测对账不靠人眼，defects.json 就是标准答案。"

### 镜头 3｜一条命令端到端（约 45 秒）

画面：终端跑 run，随后滚动展示 JSON 的 findings 与 summary。

```bash
py -X utf8 -m mrqc run --input data/paired/defect_C-LAB-02_01
```

口播：
"一条命令端到端。五节点流水线：解析 → LLM 兜底 → 质控 → 汇总 → 导出。看输出：33 条规则参评，这条记录不通过——C-LAB-01 危急值没有病程处置记录，依据是《医疗质量安全核心制度要点》国卫医发 2018 年 8 号，条文摘录逐字引用，病历证据逐字摘自检验报告部件。LLM 未配置就自动走纯规则通路，配置了也只补抽低置信字段，每条都要过防幻觉回验。"

### 镜头 4｜docx 报告（约 40 秒）

画面：终端导出 → 打开生成的 docx，滚动展示签署栏/汇总表/结论清单。

```bash
py -X utf8 -m mrqc run --input data/paired/defect_C-LAB-02_01 --report benchmarks/m5_report_sample.docx
```

口播：
"加一个 --report，质控报告直接落成 Word。首页免责声明、患者基本信息、分级统计、逐条结论——每条都带文号、条款、原文摘录和病历证据；最后是质控医师签署栏，自动结果必须人工复核签字后才能归档。报告内零外链，断网也能完整打开。"

### 镜头 5｜Web 面板（约 45 秒）

画面：起服务 → 浏览器上传部件 → 展示结论卡片。

```bash
py -X utf8 -m mrqc.web --port 8000
# 浏览器打开 http://127.0.0.1:8000
# 选择 data/paired/defect_C-LAB-02_01/ 下 5 个部件 txt → 开始质控
```

口播：
"Web 面板是免构建的单页应用，CSS、JS 全内联——**拔掉网线照样演示**。上传五份病历部件，按内容自动识别，不用关心文件名。结论实时展示：总体结论徽章、分级统计、每条非通过结论的依据与证据。/docs、/redoc 显式关闭，页面没有任何一个外部请求。"

（录制提示：可开 DevTools Network 面板清零后重放上传，证明除同源 API 外零请求。）

### 镜头 6｜基准与指标（约 40 秒）

画面：终端连跑两个基准，展示门槛模式退出码。

```bash
py -X utf8 -m mrqc benchmark parse
py -X utf8 -m mrqc benchmark detect
echo "exit=$?"
```

口播：
"指标不是口号，是带门槛的基准命令：解析 F1 一点零零（七千六百六十四个字段零错配）；端到端检出率 100%，干净对照误报 0，非 pass 结论依据关联率 100%。门槛不达标直接退出码 1，CI 挡住回归。全部离线、固定 seed、可复现。"

### 镜头 7｜收尾（约 20 秒）

画面：`mrqc demo` 输出 + README 基准表格。

```bash
py -X utf8 -m mrqc demo
```

口播：
"六类部件解析、33 条规则全挂依据、LLM 兜底防幻觉、报告与面板双交付形态——都建立在可复现的合成数据和基准之上。真实病历上的表现，等真实标注数据来验证。代码开源，欢迎克隆复跑。"

（结尾字幕：免责声明 + 合成数据声明，与 README 措辞一致。）
